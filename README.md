# 📊 Calendário Financeiro Projetivo

App online para controle financeiro pessoal com projeção futura.

## ✨ Funcionalidades

- 💰 **Salário / Renda Fixa** — cadastre receitas mensais recorrentes
- 📥 **Entradas Extras** — freelance, bônus, 13º (com data específica)
- 📋 **Contas Fixas** — aluguel, internet, celular, streaming (com dia de vencimento)
- 💳 **Parcelas de Cartão** — informe valor, total de parcelas, parcela atual e dia de vencimento. O app calcula automaticamente até quando vai e soma no mês certo
- 📤 **Saídas Avulsas** — gastos pontuais (com data)
- 📅 **Calendário** — navegue mês a mês e veja o saldo projetado dia a dia
- 📈 **Projeção de 12 Meses** — gráfico e tabela completa
- 💾 **Salvamento Automático** — dados ficam salvos no navegador (LocalStorage)
- 📥 **Exportar CSV** — para abrir no Excel/Google Sheets
- 📤 **Exportar/Importar JSON** — faça backup e restaure seus dados

## 🚀 Como publicar no GitHub Pages

1. Crie um repositório no GitHub (ex: `meu-financeiro`)
2. Faça upload de **todos os arquivos** desta pasta
3. Vá em **Settings → Pages**
4. Em "Source", selecione a branch `main` e pasta `/ (root)`
5. Clique em **Save**
6. Seu app estará em: `https://seuusuario.github.io/meu-financeiro`

## 📱 Como usar no celular

Depois de publicado, acesse pelo celular e:
- **Chrome:** Menu → "Adicionar à tela inicial"
- **Safari:** Compartilhar → "Adicionar à Tela de Início"

O app funciona como um app nativo, offline, com os dados salvos localmente!

## ⚠️ Importante

- Os dados são salvos **apenas no navegador** do dispositivo
- Use o botão **"Exportar Backup"** regularmente para não perder dados
- O app não envia dados para lugar nenhum — é 100% privado
