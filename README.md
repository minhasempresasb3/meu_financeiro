# 📊 Calendário Financeiro Projetivo v2

App online para controle financeiro pessoal com projeção futura e ajustes por dia.

## ✨ Funcionalidades

- 💰 **Salário / Renda Fixa** — receitas mensais recorrentes
- 📥 **Entradas Extras** — freelance, bônus, 13º (com data específica)
- 📋 **Contas Fixas** — aluguel, internet, celular, streaming (com dia de vencimento)
- 💳 **Parcelas de Cartão** — valor, total de parcelas, parcela atual e dia de vencimento
- 📤 **Saídas Avulsas** — gastos pontuais (com data)
- ✏️ **Ajustes por Dia** — clique em qualquer dia do calendário para adicionar/editar valores específicos daquele dia
- 📅 **Calendário** — navegue mês a mês e veja o saldo projetado dia a dia
- 📈 **Projeção de 12 Meses** — gráfico e tabela completa
- 💾 **Salvamento Automático** — dados no LocalStorage
- 📥 **Exportar CSV** — para Excel/Google Sheets
- 📤 **Exportar/Importar JSON** — backup completo

## ✏️ Como usar os Ajustes por Dia

1. Vá na aba **"Calendário"**
2. **Clique em qualquer dia** do mês
3. No modal que abre, você vê:
   - O **saldo projetado** daquele dia
   - Os **lançamentos automáticos** (salário, contas fixas, parcelas)
   - Uma seção para adicionar **ajustes manuais**
4. Digite o nome, valor e tipo (entrada ou saída) e clique em **+**
5. O ajuste aparece no calendário com um ✏️ e muda a projeção

Isso serve para:
- Salário que mudou de valor em um mês específico
- Conta extra que apareceu (ex: conserto do carro)
- Bônus ou 13º em um mês específico
- Qualquer variação que não se repete todo mês

## 🚀 Publicar no GitHub Pages

1. Crie um repositório no GitHub (ex: `meu-financeiro`)
2. Faça upload de **todos os arquivos** desta pasta
3. Vá em **Settings → Pages**
4. Em "Source", selecione a branch `main` e pasta `/ (root)`
5. Clique em **Save**
6. Seu app estará em: `https://seuusuario.github.io/meu-financeiro`

## 📱 Instalar no celular

Acesse pelo celular e:
- **Chrome:** Menu → "Adicionar à tela inicial"
- **Safari:** Compartilhar → "Adicionar à Tela de Início"

Funciona como app nativo, offline, com dados salvos localmente!

## ⚠️ Importante

- Dados salvos **apenas no navegador** do dispositivo
- Use **"Exportar Backup"** regularmente
- O app não envia dados para lugar nenhum — 100% privado
